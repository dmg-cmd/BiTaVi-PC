# 📦 BiTaVi PC - Paquetes de Distribución y Ejecutables (v1.0.8-alpha)

En este directorio se encuentran los ejecutables listos para usar de **BiTaVi PC**:

| Archivo | Tipo | Plataforma | Descripción |
| :--- | :--- | :--- | :--- |
| **`BiTaVi-v1.0.8-alpha-setup.exe`** | Instalador Nativo | Windows (x64) | Instalador guiado de escritorio con asociaciones de archivos (`.gpx`, `.kml`, `.kmz`, `.zip`). |
| **`BiTaVi-v1.0.8-alpha-portable.exe`** | Ejecutable Portable | Windows (x64) | Aplicación nativa autónoma de 1 solo archivo, sin instalación previa. |
| **`BiTaVi-PC-v1.0.8-alpha-Windows.zip`** | Paquete Portable | Windows | Paquete portable para ejecutar con `Iniciar BiTaVi PC.bat`. |
| **`BiTaVi-PC-v1.0.8-alpha-Linux.zip`** | Paquete Portable | Linux / macOS | Paquete portable para ejecutar con `./Iniciar BiTaVi PC.sh`. |

---
> Para descargar las últimas versiones compiladas directamente desde la nube, visita la sección [Releases de GitHub](https://github.com/dmg-cmd/BiTaVi-PC/releases).
